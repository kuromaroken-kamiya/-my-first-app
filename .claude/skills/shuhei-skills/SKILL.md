# しゅうへいスキル（入口）

フリーランスの学校（しゅうへい）の配布スキル13個をまとめて呼び出すための入口。

スキル本文はこのリポジトリには置かず、**MCPサーバーから都度読み込む**。
（配布スキル／クローズドコミュニティ限定スキルのため、本文を複製・再配布しない）

## 使い方

1. 下の一覧から、相談内容に合うスキルIDを選ぶ
2. MCPサーバーの `get_skill` ツールに、そのIDを `name` として渡して本文を取得する
   - サーバー名は環境により異なる（フリーランスの学校の配布スキルMCPサーバー）
   - IDが分からないときは先に `list_skills` を呼んで最新の一覧を確認する
3. 返ってきた本文の指示に従って作業を進める

迷ったら、まずユーザーに「今いちばん困っているのはどれですか？」と聞いて、下の分類から選んでもらう。

## 注意

- 一覧は固定ではない。スキルが増減している可能性があるので、`list_skills` の結果が正とする。
- MCPサーバーに接続できないときは、その旨を伝えて止める。本文を記憶から再現しない。
